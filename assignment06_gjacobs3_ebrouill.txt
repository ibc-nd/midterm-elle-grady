# Profile-based searching (hmmer) uses a probability model to quickly compare multiple references sequences to an unknow sequence. Pairwise alignemnt creates the "guide" that will be used to compare to unknowns. The profile based-searching uses the guide to investigate an unknown. These two are used in conjuction to first generate a reference and then search with that reference as a guide. 
wants to investigate the probability of structural similarities across genes.
b) # An HMM profile is more flexible and will conserve more data than a BLAST query. A BLAST query is going to try to match the unknow sequence to one singular sequence, whereas the hmm profile can adjust for the slight variabilites that may be present. Point mutations may occur that do not affect the outcome of transcription and translation. BLAST would show an issue matching a mutation, but the hmm profile would account for this variability if a previous sequence also shared the variability. Overall, greater reference sequences allows for a greater match confidence to unknown sequences.
